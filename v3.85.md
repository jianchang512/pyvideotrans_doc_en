## v3.85 Update Log

- Optimized UI layout. Less commonly used parameters are now hidden by default to avoid cluttering the interface with numerous options upon startup.
- Added speaker recognition functionality.
- Replaced the noise reduction model with a smaller, more efficient one.
- Changed the source code deployment method to uv.
- When batch translating videos, users can now specify "Sequential Serial" mode in the advanced options.
- Changed the "Equal Split" mode to batch inference. When using faster-whisper, batch inference can accelerate processing.
- EdgeTTS now allows separate configuration for concurrency count and failure retry attempts in the advanced options.
- Optimized alignment strategies.
- Fixed other known issues.
