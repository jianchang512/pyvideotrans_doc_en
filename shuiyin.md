## Batch Add Image Watermark to Videos

Open the menu -> Tools -> Add Watermark to Video, the interface is shown as below

![](https://pvtr2.pyvideotrans.com/images/shuiyin1.jpg)

1. Select the video file(s) to add the watermark to. You can choose one or multiple files.
2. Select the watermark image.
3. Choose the watermark position: top-left, top-right, bottom-right, bottom-left, or center of the video.
4. Set the margin distance from the top/bottom edges and from the left/right edges. The default is 10 pixels.
5. Set the watermark size. It is recommended to prepare the image with the desired dimensions in advance and set this size to the actual image size to prevent distortion. The default is 50x50, meaning a width of 50px and a height of 50px.
6. Click "Start Execution", wait for the process to complete, and then open the result save directory to view the output files.
