# Why Does This Documentation Website Have Ads?


This is a fully open-source and free software, with its complete code available on [GitHub](https://github.com/jianchang512/pyvideotrans). The software has no built-in ads, login or registration requirements, feature restrictions, or paid channels.

> The software includes some third-party commercial API interfaces (e.g., DeepSeek, ByteDance, Gemini, etc.). You need to fill in your own SK keys (stored locally only). Any fees incurred are charged by the third parties and are unrelated to this software. The software only provides the technical specifications for API integration.

**All revenue sources for the project:**

- One source is voluntary donations from users, made by scanning the WeChat/Alipay QR codes in the donation pop-up window at the bottom right of the software or on this documentation site.
- Another is monthly donations from users in the tech community.
- The third is Google Ads on this documentation site.

> The WeChat public account (pyvideotrans) averages less than $0.14 in daily revenue, which is negligible.

These modest earnings barely cover the token consumption needed for the documentation site server and the BBS Q&A site's AI auto-replies, saving me from paying out of pocket. They also leave a little extra for my daily cup of Luckin coffee ☺. This is a key reason the project has been maintained from October 2023 to the present.
