## How to Set Subtitle Font Size

Soft subtitles cannot be resized; their size is controlled by the player. Hard subtitles can be adjusted by modifying the `Hard Subtitle Font Pixel` size in **Menu -- Tools/Options - Advanced Options**. The default size is 14.

## Controlling the Number of Characters per Line in Subtitles

By default, CJK (Chinese, Japanese, Korean) subtitles display 30 characters per line, while subtitles in other languages display 60 characters per line. You can adjust this by modifying the `CJK Subtitle Characters per Line` and `Other Language Subtitle Characters per Line` settings in **Menu -- Tools/Options - Advanced Options**.
