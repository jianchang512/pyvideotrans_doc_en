This is a free and open-source software that provides extensive support for third-party APIs and models. Encountering bugs and usage issues is normal. You can try to resolve problems through the following methods.

- **Read the Documentation**  https://www.pyvideotrans.com

- **Ask Questions Online**  https://bbs.pyvideotrans.com

- **Discord Chat System, Invitation Link** https://discord.gg/s4jU6jeM

- **Post an Issue on GitHub**   https://github.com/jianchang512/pyvideotrans/issues

- **Send a private message on the WeChat Official Account; AI provides intelligent replies.**




## Please Note When Asking Questions:

- You must provide a full screenshot of the software at the time of the error, showing the version number in the top-left corner and the selected options within the software.

- If there are red error messages, they need to be shown in the screenshot.

- Open the `logs` folder in the software directory and upload the latest log file, or copy the last 30 lines of that file from the time of the error.



## Question Etiquette:

- Remember this is free software. Anyone can download and use it for free. The developer does not charge users any fees and therefore has no obligation to necessarily reply to your questions. However, polite questions and detailed error information help in receiving timely responses.

- As a non-profit, open-source project created out of interest, it cannot provide dedicated human customer service or specialized maintenance support. If you find too many bugs or are very dissatisfied with the experience, you can choose products offered by other commercial companies. There is no need to create a post specifically to complain; it harms others without benefiting yourself. Polite suggestions and feature requests are, of course, welcome and can be posted on GitHub Issues.





## Helping with Project Maintenance

> The project's continued existence or maintenance is not guaranteed. However, if it receives some help, the possibility is greater. If you believe this project is worth long-term maintenance, please consider helping the project in the following ways.

- Submit a Pull Request (PR) on GitHub (https://github.com/jianchang512/pyvideotrans) to help fix bugs or optimize the code.

- Write usage documentation, common problem solutions, usage tips, tutorial videos, etc. You can send the relevant website links via private message on the official account. The developer will recommend them on the GitHub ReadMe and the documentation site.

- Provide a small donation. You can open this URL **[https://pyvideotrans.com/about](https://pyvideotrans.com/about)** and scan the WeChat or Alipay QR codes on the webpage to make a small contribution. The donation amount and related information will be displayed on that page.
