## gtts dubbing channel

![image.png](https://pvtr2.pyvideotrans.com/images/68127c1a99b947539842f9d12a7bd16f~tplv-73owjymdk6-jj-mark_0_0_0_0_q75.webp)

This is Google's free dubbing channel. A proxy must be configured to use it. If you are using v2ray, set the network proxy address to `http://127.0.0.1:10809`. If you are using Clash, set the network proxy address to `http://127.0.0.1:7890`.
