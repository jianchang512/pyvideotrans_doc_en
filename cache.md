## Clear Cache Feature

In video translation, to speed up the process, some files are cached by default. When translating the same file a second time, if a cache exists, it will be used directly. If you do not want this, please refer to this article for handling.



- In the `Menu Bar - Tools` menu, click and select "Clear Cache" to remove all settings and temporary files cached on this machine.

**Note: The software will close automatically after clearing. You need to open it manually.**


![](https://pvtr2.pyvideotrans.com/images/b39375fed5232ee836122d4c2e82822c.jpg)


![](https://pvtr2.pyvideotrans.com/images/082af5a3f36e86749899d547c472dabb.jpg)

- You can also check the **Clear Existing** checkbox next to the **Select Video** button. This will also achieve the purpose of clearing the cache before translation.
