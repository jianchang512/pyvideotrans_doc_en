The standalone Claude channel was removed after version v3.85. Please use the `OpenAI ChatGPT` compatible channel.

Please click **Menu -> Translation Settings -> OpenAI ChatGPT Compatible**

![](https://pvtr2.pyvideotrans.com/1763547696068_image.png)

API URL: `https://api.anthropic.com/v1/`

SK: Enter your SK

In the model text box, enter the model you wish to use, for example:
```
claude-sonnet-4,claude-sonnet-4-5,claude-opus-4,claude-opus-4-1

```

Then, select the model you want to use from the dropdown list under **Model**, and save.
