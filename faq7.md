## Software Displays English Interface, How to Display Chinese Interface

> By default, the software detects the current system language. If it's Chinese, the interface displays in Chinese; otherwise, it displays in English.

Go to Menu Bar > Tools/Options > Advanced Options, find the Interface setting, set it to `zh`, save and restart for Chinese interface, or set to `en`, save and restart for English interface.
