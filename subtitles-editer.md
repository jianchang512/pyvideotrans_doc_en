## Batch Subtitle Translation

This feature is used to import local subtitles for editing and modification, and then export the modified subtitles locally. It supports three subtitle formats: srt, vtt, and ass.

![](https://pvtr2.pyvideotrans.com/images/subtitles-edit01.jpg)

**How to Use**

1. Click the import button or drag and drop a subtitle file onto the blank area. The software will automatically render and create an editable element for each subtitle line.
2. You can adjust the start time, end time, and text of each subtitle line, or delete a line, or add a new line.
3. At the bottom, you can choose the subtitle export format. When selecting the ass format, you can set the exported font, font size, text color, text background color, text border color, and the distance of the subtitle from the left margin, right margin, and bottom margin.

Note:

1. The display of text background color and text border color may vary across different media players and might not be shown.
2. Only one subtitle file can be imported at a time.

## Translation Feature

To facilitate users in modifying subtitles and viewing comparisons between the original text and translated text during the editing process, we have added a translation feature to the subtitle editing window. The translated text will automatically appear below the original text, allowing users to easily compare and make modifications. After editing, users can choose to export subtitles in the target language, bilingual subtitles, or the original language subtitles.

![Subtitle Translation](https://pvtr2.pyvideotrans.com/img/20241105225453-0.webp)

The operation is also very simple. Just select the translation service, set the source language and target language, and then click the translate button. The software will automatically insert the translation results below the text box of each subtitle line, making it easy for users to intuitively compare and adjust modifications.

![Translation Feature](https://pvtr2.pyvideotrans.com/img/20241105225454-1.webp)

This feature significantly enhances the convenience of subtitle editing. Users can easily complete subtitle modifications and translation operations within the same interface, saving a lot of time and effort.
