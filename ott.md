## Using OTT Offline Translation in Video Translation and Dubbing Software

1. First, deploy OTT from https://github.com/jianchang512/ott. You can deploy from source code. For Windows, there is an exe package available. Download it, extract it, and double-click to run.

2. After OTT starts, the address will be displayed in the **black window**, for example, the default is http://127.0.0.1:9911. Enter this address in the video translation and dubbing software under Menu Bar -> Settings -> OTT_address. If you have modified the default address, make sure to enter the correct one.
