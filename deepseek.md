Want to try the full-power 671B Deepseek-r1 for free with web and API access? There aren't many options on the market!

-   **deepseek.com official**: The web version is free and offers the best performance, but there is no free API quota, and top-ups are currently paused.
-   **ByteDance Volcano Ark / Silicon Flow, etc.**: Provide the full-power R1 version and API, but offer no free quota.
-   **Baidu Intelligent Cloud Qianfan ModelBuilder**: Offers a limited-time free trial of the full-power R1 version and API. Unfortunately, the interface is not OpenAI-compatible, making it inconvenient to use.
-   **302.ai and other cloud service providers**: Mostly offer partial free quotas for the web version but do not provide free API quotas.

After a comprehensive review, currently, the only platforms I've found that offer sufficient free quota, provide the full-power R1, and support OpenAI-compatible API calls are: **Tencent Cloud Ti Platform** and **Alibaba Cloud Bailian**.

## Alibaba Cloud Bailian

**Service Activation and API Usage Instructions**

**I. Service Activation**

1.  **Registration & Login**: Visit the Alibaba Cloud Bailian Console at https://bailian.console.aliyun.com, register an Alibaba Cloud account, and log in.
2.  **Real-name Verification**: Complete the real-name verification process as prompted.
3.  **API Key Creation**: Go to the API Key Management page and create a new API Key at https://bailian.console.aliyun.com/?apiKey=1.

**II. API Resources and Limits**

1.  **Free Quota**: 1 million tokens of free call quota.
2.  **Call Limits**:
    *   Maximum calls per minute: 60
    *   Maximum token consumption per minute: 100,000

**III. OpenAI-Compatible API**

For developer convenience, Alibaba Cloud Bailian provides an interface compatible with the OpenAI API:

*   **API URL:** `https://dashscope.aliyuncs.com/compatible-mode/v1`
*   **API Key (SK):** Use the API Key you created on the "API Key Management page".
*   **Available Models:** `deepseek-r1`, `deepseek-v3`
