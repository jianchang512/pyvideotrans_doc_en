## Translation Connection Failed

![](https://pvtr2.pyvideotrans.com/images/dda034ede619396291772f3f1907ae4d.jpg)

The prompt indicates unable to connect to Google or ChatGPT.
Due to reasons you are aware of, these two services cannot be used normally within China. If you wish to use them, you must ensure you have mastered the method of accessing the internet via a proxy and have filled in the network proxy address in the "Network Proxy Address" text box. Simply enabling a global proxy may be ineffective; the safer method is to manually fill it in the "Network Proxy Address" text box.

![](https://pvtr2.pyvideotrans.com/images/2adbc24b72ae7c26b8fc9ae2a338bcfb.jpg)

This text box requires filling in the "Network Proxy Address," not your API relay address. Some users who use ChatGPT mistakenly fill in a third-party API relay address here, which will absolutely and certainly cause an error. The API address needs to be filled in under "Settings Menu - Openai/ChatGPT Key."

![](https://pvtr2.pyvideotrans.com/images/caaa37be084d0547d80b24d2b0714346.jpg)
