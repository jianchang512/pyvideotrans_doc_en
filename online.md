Video translation and dubbing now supports API calls. Leveraging this API, we have launched an online tool for video translation and dubbing. No registration or login is required. Simply visit (https://tts.pyvideotrans.com) in your browser to experience the full service.

It features four core functions: **Speech Recognition**, **Text-to-Speech Synthesis**, **Subtitle File Translation**, and **Video Translation**. The following detailed steps and explanations will help every new user get started easily.

---

## 1. Text-to-Speech Synthesis

**Description:** This function converts text or SRT subtitle files into dubbed audio. You can select a voice role, adjust the speech rate, and generate the corresponding audio file, which can be previewed online or downloaded.

**Steps:**

1.  Open the Text-to-Speech Synthesis page.
2.  Select the **Subtitle Language**, which is the language of the text to be dubbed.
3.  Choose a **Voice Role**; each role has a different vocal style.
4.  Optionally adjust the **Speech Rate** and **Volume** below.
5.  Select the output **Audio Format**. If you choose MP3, you can preview it online after generation; other formats require downloading to play.
6.  Paste or upload an **SRT format subtitle file**, or directly input the text you want to dub.
7.  Click the "**Start Dubbing**" button. Wait a moment, and the result will be generated and displayed.

![image.png](https://pvtr2.pyvideotrans.com/img/online1.webp)

> The full-featured video translation software supports over ten dubbing channels including `edge-tts/ChatTTS/GPT-SoVITS/CosyVoice/openai-tts/azure-tts/elevenlabs.io/fishTTS/gtts`. The online version only supports edge-tts, which is free, saves server resources, and has no usage limits.

## 2. Speech Recognition

**Description:** Transcribes human speech from a video or audio file into text and displays it on the page.

**Steps:**

1.  Open the Speech Recognition page.
2.  Select the **Source Language**, i.e., the language spoken in the audio or video.
3.  Click to **upload a local audio or video file** (supports common video and audio formats).
4.  Click the "**Start Recognition**" button. Wait a moment, and the system will automatically process and generate the transcribed text.
5.  The recognition result will appear in the text box. You can copy this text or directly click the **Download** button to save it.

![image.png](https://pvtr2.pyvideotrans.com/img/online2.webp)

## 3. Subtitle File Translation

**Description:** This function translates SRT format subtitle files into a target language while preserving the original subtitle format.

**Steps:**

1.  Open the Subtitle File Translation page.
2.  Select the **Source Language**, i.e., the language of the subtitle you want to translate.
3.  Select the **Target Language**, i.e., the language you want to translate into.
4.  Upload an **SRT format subtitle file**.
5.  Click the "**Start Translation**" button. The system will process the translation and display the result in the right-hand text box.
6.  You can copy the translation result or directly click the **Download** button to save the translated subtitle file.

![image.png](https://pvtr2.pyvideotrans.com/img/online3.webp)

## 4. Video Translation

**Description:** Translates the original speech in a video into a target language's pronunciation, automatically generates corresponding subtitles, and supports embedding subtitles into the video. For example, if you download an English video from YouTube, you can use this function to translate it into a Chinese video, where the speech becomes Chinese and the subtitles also become Chinese.

**Steps:**

1.  Open the Video Translation page.
2.  Select the **Original Source Language**, i.e., the language spoken in the video.
3.  Select the **Target Language**, i.e., the language for the translated video's speech.
4.  Choose a **Voice Role**.
5.  If you need synchronized subtitles, you can select "**Align Subtitles**", which will keep the video's subtitles consistent with the new dubbing.
6.  Upload a **local video file**.
7.  Click the "**Start Video Translation**" button. Wait a moment, and the system will automatically process and generate the translated video.
8.  The result will be displayed at the bottom of the page. You can **watch the translated video online** directly or download other materials, such as SRT subtitles, the original video's audio, or the dubbed audio.

![image.png](https://pvtr2.pyvideotrans.com/img/online4.webp)

> **Note:** To display subtitles directly in the web page, choose the "**Hard Subtitles**" embedding method. If you choose "Soft Subtitles", you need to download the video to your local computer and watch it with a player that supports subtitle display.
