# FireRed-TTS2 Xiaohongshu TTS2 One-Click Integration Package

> Download Link: https://pan.baidu.com/s/14i_l85eplfeXp0otfY_O0Q?pwd=zcwt


## How to Use

1. Download and extract the package.
2. Double-click `双击启动.bat` (Double-click to start.bat).
3. The first launch will download the FireRed-TTS2 model. The total model size exceeds 20GB, which may take some time. Please be patient.
4. By default, the model is downloaded from the `hf-mirror.com` mirror site. If you have access to scientific internet and wish to download from `huggingface.co`, please delete the `pretrained_models` folder, edit `双击启动.bat`, remove the line `set HF_ENDPOINT=https://hf-mirror.com`, and then restart the application.
