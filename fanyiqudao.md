# Translation Channels (Subtitle Translation)

Translation channels translate subtitles from their original language into other languages—for example, converting Chinese subtitles into English, or vice versa. It connects to various translation services to quickly and accurately translate subtitles generated by speech recognition into your desired target language.

> Some translation services require information such as an API URL, Secret Key (SK), etc. You can easily configure them under the **Translation Settings** option in the top menu bar of the software.
>
> [Translation results may show blank subtitle lines or large chunks of text. Click here to see why](/faq17). Solution: `Menu → Tools → Advanced Options → Subtitle Translation → Lines per batch for traditional translation channels / Lines per batch for AI translation → Set both to 1`

---

## Free Translation Channels

These channels are usually free to use, but they may have network restrictions or usage rate limits.

*   **[Google Translate](/googletranslate)**: Reliable translation quality. However, users in mainland China will need a VPN/proxy.
*   **[Microsoft Translate](/microsoft)**: Provided by Microsoft. It works without special network requirements, but it may temporarily become unavailable if too many requests are sent in a short period.

## Local Translation Models

*   **[M2M100](/m2m100)**: Local model translation. It automatically downloads the model online on first use. Download link: https://modelscope.cn/models/himyworld/videotrans/files
*   **Hy-MT2-1.8B Local Model**: Tencent's text translation model. It automatically downloads the model online on first use. Download link: https://huggingface.co/tencent/Hy-MT2-1.8B/tree/main
	> If the initial model download fails, you can open this link, download all files, and copy them to overwrite `software_directory/models/models--tencent--Hy-MT2-1.8B`
	>
	> It uses the smaller 1.8B model by default. If you want to use the larger 7B/30B models, please manually visit https://huggingface.co/tencent/Hy-MT2-7B/tree/main to download all files and paste them into the `software_directory/models/models--tencent--Hy-MT2-1.8B` folder to overwrite the existing files.

## Professional Translation Services Requiring an API Key

These are dedicated machine translation platforms. They usually require registering an account, creating an application, and obtaining an API Key before use. They offer higher stability and reliable translation quality.

*   **[Baidu Translate](/baidu)**: Official translation service provided by Baidu. You need to visit the [Baidu Translate Open Platform](https://fanyi-api.baidu.com/), create an application, and get your AppID and key. Please note that this service is restricted to Mainland China IP addresses.
*   **[Tencent Translation](/tencent)**: Machine translation service by Tencent Cloud. You need to log in to [Tencent Cloud](https://cloud.tencent.com/product/tmt), activate the service, and create access keys (SecretID and SecretKey). This service is also restricted to Mainland China IP addresses.
*   **[Alibaba Machine Translation](/alibaba-machine-translation)**: Professional translation service from Alibaba Cloud. You need to visit the Alibaba Cloud website to activate the service.
*   **[DeepL Translate](/deepl)**: Renowned for its high-quality and natural-sounding translations. You need to register on its [official website](https://www.deepl.com) and activate the service (requires an international credit card).

## AI Large Language Model Translation Channels

These channels use advanced artificial intelligence models for translation, producing more natural, context-aware, and human-like results.

*   **[DeepSeek](/deepseek-ai)**: A company focusing on LLM research and development. You need to visit their open platform to apply for an API key.
*   **[ByteDance Volcano Engine](/zijiehuoshan)**: Provided by ByteDance's Volcano Engine. You need to visit their official website to activate the service and create an inference endpoint.
*   **[Zhipu AI](/zhipu-ai)**: A leading AI company in China. You need to visit the [Zhipu AI Open Platform](https://open.bigmodel.cn/) to apply for an API key.
*   **[Alibaba Bailian API](/qwen-mt)**: Large language model platform launched by Alibaba Cloud. You need to visit the [Alibaba Bailian Platform](https://www.aliyun.com/product/bailian) to apply for an API key.
*   **[SiliconFlow](/siliconflow-ai)**: A company specializing in AI technical services. You need to visit their official website to apply for an SK (Secret Key).
*   **[302.AI Translation](/302ai)**: Visit the `302.ai` website and apply for an app key to use it.
*   **[OpenRouter.ai](/openrouter-ai)**: A platform that aggregates multiple AI models. You need to visit its official website to apply for an API key.
*   **[OpenAI (ChatGPT)](/openai)**: The famous ChatGPT, delivering outstanding translation quality. You can use official OpenAI models or configure compatible third-party/relay APIs.
*   **[Gemini Translation](/gemini-recognition)**: Google's powerful AI model. You need to visit the Google AI platform to apply for a Gemini API key. Users in mainland China will need a VPN/proxy.
*   **[AzureGPT Translation](/azure)**: AI translation service provided by the Microsoft Azure Cloud platform. You need to activate an Azure account and service.

## Self-Hosting and Customization

Ideal for users with technical experience, giving you greater freedom and control.

*   **[DeepLX Translation](/deeplx)**: An open-source project that allows you to use DeepL services for free; requires deployment on your own local machine or server.
*   **[LibreTranslate](/libretranslate)**: An open-source machine translation software that you need to host yourself before using.
*   **[Compatible AI / Local Model Translation](/localllm)**: If you host a local LLM on your own computer or server (OpenAI API-compatible), you can enter the API URL here to connect directly.
*   **[Custom Translation API](/transapi)**: If you have coding skills, you can write your own translation API. As long as it returns data in the required format, it can be seamlessly integrated into our software.
