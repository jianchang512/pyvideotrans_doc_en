## glm-4-flash and qwen2.5-7b Free Large Models

Zhipu AI and Silicon Flow provide free large models that can be used as translation channels.

Since version v3.47, two new translation channels have been added: **GLM-4-flash (Free)** and **Qwen2.5-7b (Free)**.

Simply go to the Zhipu AI official website (https://bigmodel.cn/usercenter/proj-mgmt/apikeys) and the Silicon Flow official website (https://cloud.siliconflow.cn/account/ak) to create an API key, then enter it into the software under **Menu -> Translation Settings -> glm-4-flash/qwen2.5-7b** to use it for free.
