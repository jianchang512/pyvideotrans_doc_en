## A Review of Commonly Used AI Large Model Platforms

Since the groundbreaking emergence of ChatGPT 3, which sparked a wave of enthusiasm for AI large models, various AI platforms have sprung up like mushrooms both domestically and internationally. Want to experience these powerful AI capabilities? Don't worry about high costs! Many platforms offer free APIs or free credits, allowing you to explore the charm of artificial intelligence at zero cost.

This article will review some commonly used AI large model platforms that offer free trials, making it convenient for everyone to explore. While there are many other platforms on the market, the following are ones I personally use frequently and consider worth recommending.

### Domestic Platforms

1.  Moonshot AI Kimi

    Website: https://www.moonshot.cn/

    API Console: https://platform.moonshot.cn/console

    Modality: Text modality, chat, translation, etc.

    Free Credits:
    *   Maximum requests per minute: 3
    *   Maximum tokens processed per minute: 32,000
    *   Maximum tokens processed per day: Unlimited

    API Endpoint: https://api.moonshot.cn/v1

    OpenAI Compatible: Yes

    Available Models:
    *   `moonshot-v1-8k`: An 8k context length model, suitable for generating short text.
    *   `moonshot-v1-32k`: A 32k context length model, suitable for generating long text.
    *   `moonshot-v1-128k`: A 128k context length model, suitable for generating very long text.

2.  DeepSeek

    Website: https://www.deepseek.com/

    API Console: https://platform.deepseek.com/

    Modality: Text modality, chat, translation, etc.

    Free Credits: None
    API Endpoint: https://api.deepseek.com/v1
    OpenAI Compatible: Yes
    Available Model: `deepseek-chat`

3.  Zhipu AI (Tsinghua)

    Website: https://bigmodel.cn/

    API Console: https://bigmodel.cn/console

    Modality: Multimodal, text, vision, speech, etc.

    Free Credits: Each model has free credits.
    API Endpoint: https://open.bigmodel.cn/api/paas/v4/
    OpenAI Compatible: Yes
    Model Series: GLM-4, GLM-4V, CogVideoX, CogView-3-Plus, GLM-4-AllTools

4.  Baichuan AI

    Website: https://www.baichuan-ai.com/

    API Console: https://platform.baichuan-ai.com/console

    Modality: Text modality, chat, translation, etc.

    Free Credits: ¥80 credit upon registration.
    API Endpoint: https://api.baichuan-ai.com/v1
    OpenAI Compatible: Yes
    Model Series: Baichuan4, Baichuan3

5.  iFlytek Spark

    Website: https://xinghuo.xfyun.cn/

    API Console: https://xinghuo.xfyun.cn/sparkapi

    Modality: Multimodal, text, image, speech

    Free Credits: The Spark Lite model is completely free; other models offer complimentary credits.
    API Endpoint: No unified endpoint.
    OpenAI Compatible: No
    Model Series: Many

### International Platforms

1.  DeepGram

    Website: https://deepgram.com/

    Application: Speech recognition, speech synthesis
    Free Credits: $200 credit upon registration.
    OpenAI Compatible: No
    VPN Required: No

2.  ElevenLabs

    Website: https://elevenlabs.io/

    Application: Speech synthesis, voice cloning
    Free Credits: 10 minutes of audio synthesis per month.
    OpenAI Compatible: No
    VPN Required: No

3.  GroqCloud

    Website: https://groq.com/

    Application: Text chat, translation, speech recognition
    Free Credits: Generous
    VPN Required: Yes
    OpenAI Compatible: Yes
    API Endpoint: https://api.groq.com/openai/v1

4.  X.ai

    Website: https://console.x.ai/

    Application: Text chat, translation
    Free Credits: $20
    VPN Required: Yes
    OpenAI Compatible: Yes
    API Endpoint: https://api.x.ai/v1

It's important to note that free credits are typically limited. It is recommended to plan your resource usage wisely during trials and pay attention to the specific usage rules of each platform.
