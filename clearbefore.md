## Clean Up Old Files Before Execution

To speed up execution, the system checks for files generated in previous runs, such as recognized subtitles or translated subtitles. If they exist, they will be reused directly.

If you want to regenerate the files and not use the previous ones, you can select the "Clear Cache" checkbox before clicking the execute button.
