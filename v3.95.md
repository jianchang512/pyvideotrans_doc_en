# v3.95 Changelog

1. Added secondary recognition in video translation feature. Click `Set More Parameters` on the main interface to see it.
2. Added `VAD Type Switch` in Menu - Tools - Advanced Options. Default is `ten-vad`, which is faster and more accurate. You can switch back to `silero` if issues arise.
3. Faster-whisper defaults to batch inference for increased speed. In Advanced Options, set `faster-whisper Batch` to 1 for non-batch mode, which reduces speed but slightly improves accuracy.
4. Optimized automatic model downloads. It first tries `huggingface.co`; if it fails, it downloads from the domestic mirror `hf-mirror.com`.
5. Added several custom options in Advanced Options to control hallucinations.
6. Added `Script Alignment` feature, implemented simply based on `faster-whisper local model` and diff algorithm.
7. Added `supertonic` dubbing channel, supporting English, Korean, Spanish, Portuguese, and French — compact and fast.
8. Changed voice noise reduction to Alibaba's modelscope.cn default. Processing time will significantly increase, but noise reduction effect is improved.
9. Speaker diarization supports built-in Chinese-English model, pyannote 3.0 model, Alibaba cam++ Chinese-English model, and reverb-diarization-v1 model. You can switch in Advanced Options; default is built-in Chinese-English model.
10. When translating a single video, on the subtitle modification pop-up interface, you can open the subtitle folder, manually or via third-party tools modify the generated subtitle files, then click `Don't Save, Just Continue` on the interface to use the modified subtitle files, making it easy to adjust subtitles yourself.
11. Supports multi-GPU concurrency for faster processing. Select `Multi-GPU Mode` in Advanced Options.
12. Heavy tasks now use multi-processing mode to better utilize multiple cores. In Advanced Options, set a larger `Maximum Process Count` to speed up.
13. In Advanced Options - Subtitle Translation, added a `Include Original Subtitles` checkbox. When checked and using an AI translation channel, the original subtitles will also be sent to the AI, resulting in better translation quality.
14. Added command-line mode. See [CLI Command Line](/cli) for usage details.
15. Optimized default translation prompts.
16. Added support for qwen-tts open-source model.
