As is well known, Google services, including Google Translate, are inaccessible within China.

Therefore, to use the Google Translate channel in the [Video Translation and Dubbing Software](https://juejin.cn/post/7331558973657251840), you need to fill in a proxy address. This can be quite troublesome for beginners who are not familiar with using proxies.

We recommend a small tool. After running it once with administrator rights, you can use Google Translate directly without a proxy.

**First, download the tool here**

**https://pyvideotrans.com/google.zip**

After downloading, extract it to a folder. Inside, you'll find three files. Right-click on the **GoogleTranslate.exe** file and select "Run as administrator".

![](https://pvtr2.pyvideotrans.com/images/c54a69e0ed6d2cc85dc01c848eaf4a91.jpg)

A black command window will open and run automatically. When you see the prompt "**Set to Host file? (Y: Set)**", type the letter **Y** on your keyboard and press Enter. That's it. Mission accomplished. Go ahead and try it.

![](https://pvtr2.pyvideotrans.com/images/a6afc7b9ba4412e43e64ee78c0c763df.jpg)

**Don't worry if it fails; just keep reading below.**

Sometimes, due to permission issues, it might indicate failure. Please pay attention to the prompt after you input Y. Alternatively, even if no failure is indicated, you might still be unable to use Google Translate. In such cases, you need to proceed as follows.

In the same black command window (if it's closed, just right-click and open GoogleTranslate.exe again), copy the two lines of content.

![](https://pvtr2.pyvideotrans.com/images/578f4434b4ef2568a9c07c75e46b8376.jpg)

After copying, open the folder **C:\Windows\System32\drivers\etc**. That is, navigate from your system C drive, open the Windows folder, then find and open the System32 folder, then find and open the drivers folder, and finally find and open the etc folder. You will see a file named **hosts** or **HOSTS** (in uppercase). This file has no extension; don't worry, this is not an error.

![](https://pvtr2.pyvideotrans.com/images/ad8d2e1a5b8a8470931671d0aed21971.jpg)

Right-click on this file, click "Properties", uncheck the box next to "Read-only", and click OK.

![](https://pvtr2.pyvideotrans.com/images/4eb39830cd2286eb02e9c1a635312543.jpg)

![](https://pvtr2.pyvideotrans.com/images/7b4297002ff7c0b19547d40291e606b9.jpg)

Next, open this hosts file with Notepad and paste the content you just copied.

![](https://pvtr2.pyvideotrans.com/images/8081a3ad99e440411a8203f73ea02ab8.jpg)

Save the file, and you're done. Go and try visiting https://translate.google.com.

You should now be able to access it.
